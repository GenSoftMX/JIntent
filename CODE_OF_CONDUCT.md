# Code of Conduct

## Our Pledge
We want this project to be a safe and professional space for collaboration.  
All contributors are expected to treat each other with respect and courtesy.

## Standards
Positive behavior includes:
- Being respectful and constructive in discussions.
- Giving and receiving feedback professionally.
- Focusing on technical solutions and project goals.

Unacceptable behavior includes:
- Insults, offensive comments, or personal attacks.
- Harassment of any kind.
- Disruptive or aggressive behavior.
- Sharing others’ private information without permission.

## Responsibilities
Project maintainers may remove or reject contributions that violate this Code of Conduct.  
Serious or repeated violations may lead to being permanently banned from the project.

## Scope
This Code of Conduct applies in all project spaces (issues, pull requests, code reviews, discussions) and when representing the project in public.
